# Documentação

Guarde aqui somente documentos públicos e essenciais para entender ou avaliar o projeto.

Use nomes claros, como `casos-de-uso.pdf` ou `testes-mvp.md`. Não crie subpastas, a menos que a equipe realmente passe a precisar delas.

Planejamentos internos, anotações privadas e materiais que não devem ficar públicos devem ser mantidos no repositório privado da equipe ou em uma pasta compartilhada fora deste projeto.
